# 🏥 Hospital Appointment System

A full-stack hospital appointment booking platform with separate patient and admin interfaces, built with React and a Node.js/Express/MongoDB backend.

🔗 **Live Demo:** [Patient App](https://react-5da8esuf4-satyam-s-projects8.vercel.app/) 
| [Admin Panel](https://hospital-admin-theta.vercel.app/)

## Features
- 🔐 Secure JWT-based authentication for patients, doctors, and admins
- 📅 Patients can browse doctors and book, view, or cancel appointments
- 👨‍⚕️ Admin panel to manage doctor profiles and approve/manage appointments
- ⚡ Single Page Application with client-side routing (Vercel SPA rewrite config)
- 📱 Responsive UI

## Tech Stack
**Frontend:** React, JavaScript  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Auth:** JSON Web Tokens (JWT)  
**Deployment:** Vercel
